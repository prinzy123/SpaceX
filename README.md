### [`voice-agent/`](voice-agent/) — Personal Voice AI Assistant

An AI assistant that handles bookings, reservations and appointments, and can
**phone businesses and hold the conversation for you**. Works three ways: as a
terminal/voice app you run, as tools inside Claude (via MCP), or as a ChatGPT
Custom GPT.

New to APIs? Start with
[`voice-agent/docs/01-beginner-guide.md`](voice-agent/docs/01-beginner-guide.md).

Try it with no API key at all:

```bash
cd voice-agent && pip install -r requirements.txt
python -m assistant.cli --provider echo
```
